# Zenvu

Zenvu — независимый каталог для Android с публично доступными прямыми трансляциями телевидения, онлайн-радио и веб-камер. Приложение работает на телефонах, Android TV и Google TV.

Zenvu не размещает, не владеет и не управляет видео- и аудиопотоками. Это не официальный клиент какого-либо канала, и приложение не связано с Famelack или iptv-org. Списки каналов берутся из публичного набора данных (лицензия MIT, Copyright 2026 Famelack LLC).
