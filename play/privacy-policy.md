# Zenvu privacy policy

Zenvu is an independent directory for publicly listed live TV, radio, and webcam streams. It is not the official Famelack application and it is not operated by the channels, stations, or camera owners.

## What stays on the device

Zenvu does not ask for an account. It stores these items only on the phone or TV:

- favorite channels, stations, and webcams
- theme and playback preferences
- the last country selection
- downloaded listing files, so the directory can open without a network

Clear saved listings in Settings. Uninstalling the app removes the rest.

## What leaves the device

The app does not include an analytics or advertising SDK, and it does not sell personal information.

To show the directory, Zenvu downloads JSON files from GitHub (`raw.githubusercontent.com`, repository `Valijonzoda/famelack-data`). GitHub can see the IP address of that request.

When you play a listing, the device connects directly to the stream address in the dataset. The operator of that stream receives ordinary player traffic, including your IP address. Webcam listings in the current dataset are YouTube embed pages, so Google may also receive technical data when an embed loads.

Some listings are marked region locked in the dataset. Playback can fail when a stream is offline, restricted, or in a format this device cannot play.

## Permissions

- Internet and network state, to download listings and open streams
- Notifications, foreground media playback, and a wake lock, so radio can keep playing with a system control

Zenvu does not request location, contacts, camera, or microphone access.

## Contact

Zenvu does not operate the streams. Copyright questions about a specific stream should go to the operator or, for listings taken from the Famelack dataset, to the contact published by that project (`dmca@famelack.com`).
